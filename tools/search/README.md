The novelty search that found the CA family. It ran headless against `page.html`: `page.tmpl.html` (the CA page with extra hooks for loading a preset object and reading back the fields), built with `../../src/presets.js` in place of `/*PRESETS*/`. `search.js` expects `presets.js` one directory up and appends every evaluation to `archive.jsonl`, so a restart resumes where it stopped. `snap.js` and `sheet.py` render the snapshots and the contact sheet. `ca_presets.json` is the final 24.
